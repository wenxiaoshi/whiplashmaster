CORE FEATURES

让你听见自己练得准不准

不是节拍器，也不是录音软件。而是把你每一击打的时间、稳定度、力度全部数字化的私人教练。

🎯

实时鼓点识别

基于 Onset Detection 与自研 DSP 管线，毫秒级识别每次击打，判定节拍偏差与稳定度。

📊

多维评分体系

节奏 / 稳定度 / 力度 / Perfect 四大维度独立打分，Excellent 到 Practice 五档评级。

🥁

丰富节奏型库

从四分、八分、十六分到附点、切分、休止符，10 种基础节奏型自由组合练习。

📈

练习成长趋势

历史记录、热力图、评分趋势线，把每次练习都沉淀为可回溯的进步曲线。

🎨

6 套主题配色

燃橙 / 松青 / 静蓝 / 木棕 / 薄荷青 / 蜂蜜黄，含 sweet noise M1 联名主题。

⏰

每日练鼓提醒

按你的作息设置提醒时间，通知栏 inline 按钮支持「今天先不」，不打扰不遗忘。
