## 1. 首次启动

### 1.1 权限授予

首次启动会请求 **麦克风** 权限。请务必允许 — 这是 App 的核心功能所在，不允许就无法进行任何练习。

若不慎拒绝，进入手机 **设置 → 应用 → WhiplashMaster → 权限**，手动开启。

### 1.2 初始配置

进入首页后可以看到：

- **BPM 选择区**：快捷 60 / 80 / 100，或点击「自定义」调整（40-240 范围）
- **节奏型选择**：默认四分音符，可切换到八分 / 十六分 / 组合模板
- **开始练习按钮**：大橙色按钮，按下 3 秒倒计时后开始

---

## 2. 核心练习流程

### 2.1 开始

1. 选定 BPM + 节奏型
2. 点击「开始练习」
3. 3-2-1 倒计时后进入实时判定
4. 击打时会看到实时的击打反馈（准 / 早 / 晚）与力度提示
5. 完成一段（默认 8 小节，可在设置中调整）后自动进入结果页

### 2.2 结果页解读

- **四大维度分数**：节奏 / 稳定度 / 力度 / Perfect 独立展示
- **五档评级**：Excellent · Good · Fair · Poor · Practice
- **热点回放**：图上标出每次击打的偏差（超过 ±30ms 高亮）
- **音频回放**：可回听刚才的练习录音（本地暂存，24h 后自动清除）
- **分享**：可分享成绩到小红书 / 微信

### 2.3 保存到历史

点击「保存到历史」将本次练习存入本地数据库，可在「历史」Tab 回溯。

---

## 3. 历史与趋势

### 3.1 历史 Tab

- 按日期倒序列出所有练习
- 每条显示：BPM · 节奏型 · 总评分 · 时长
- 点击进入详情：可看到该次的四维分数 + 回听音频

### 3.2 热力图

一年 365 天的练习频次可视化：

- 颜色越深表示当天练习次数越多
- 长按可看具体日期与练习次数
- 支持切换年份查看历史

### 3.3 趋势图

- 折线图显示各维度评分随日期变化
- 可切换查看 7 天 / 30 天 / 90 天 / 全部区间
- 支持不同节奏型对比

---

## 4. 组合模板编辑器

进入 **首页 → 节奏型 → 组合模板 → 新建**：

1. 拖入基础节奏型（10 种可选）
2. 排列到指定拍数（4 / 8 / 16 拍）
3. 点击「预听」实时播放
4. 保存并命名，之后可在快捷选择中使用

---

## 5. 每日练鼓提醒

进入 **设置 → 提醒**：

1. 打开「每日提醒」开关
2. 设置提醒时间（默认 20:00）
3. 允许通知权限（首次开启会自动请求）

到达时间会收到系统通知：

- 点击通知直接进入首页开始练习
- 点击「今天先不」按钮跳过今日（不影响明日）

---

## 6. 主题切换

**设置 → 外观 → 主题色**，2×3 网格选择：

燃橙 · 松青 · 静蓝 · 木棕 · 薄荷青 · 蜂蜜黄

深浅色模式跟随系统，也可手动固定。

## 7. OEM 特殊适配

### 7.1 小米 / Redmi

首次运行可能被 MIUI 拦截，需要在 **安全中心 → 授权管理 → 后台弹出界面** 中允许 WhiplashMaster。

### 7.2 荣耀 / 华为

进入 **设置 → 电池 → 应用启动管理 → WhiplashMaster**，关闭「自动管理」，手动允许「允许后台活动」。

### 7.3 vivo / OPPO

进入 **设置 → 电池 → 高耗电应用**，允许 WhiplashMaster 在后台运行以确保提醒通知不被杀掉。

## 8. 常见问题

**Q: 击打没有反应怎么办？**

A: 检查麦克风权限是否开启；确保设备麦克风未被遮挡；离鼓面距离 20-50 厘米内效果最佳。

**Q: 评分偏低怎么办？**

A: 前 5 次练习通常需要习惯系统的判定精度。评分严格但公正，多练习几次能找到手感。

**Q: 数据能同步到其他设备吗？**

A: v1.5+ 支持导出 ZIP 归档，在另一台设备导入即可。云同步在 Roadmap 中，尚未实现。

**Q: iOS 版本什么时候上架？**

A: TestFlight 内测中，App Store 审核准备中，[联系加入内测](/feedback/#wechat)。
