## 🎵 内置节拍器 · 里程碑发布

WhiplashMaster v2.0 的核心命题：**Click 播放独立于判定网格**。

历史版本中 Click 与判定共享同一 position 序列，导致细分节奏型（如三连音 / 十六分）的 click 密集打乱听感。v2.0 起：

- **Pulse-only Click**：默认只在四分音符 pulse 上响，与人耳期待的"节拍感"一致
- **Subdivision 判定网格**：细分位置只做判定，不发声
- **BeatGrid 与 WaveformCanvas 分离**：三重语义（Scheduler 播放 · BeatGrid 判定 · Canvas 网格线）彻底解耦

## 新增功能

- **连续 BPM 变化**：一次练习中可从 60 渐加速到 120，或反向渐减速，专治稳定度短板
- **Click 音色切换**：木鱼 / 电子哔 / 高音鼓 / 静音四种可选
- **节拍器独立模式**：不进入练习判定，纯节拍器功能可单独使用

## 架构变更

- `MetronomeScheduler`：新增，独立于 `PracticeEngine`
- `BeatGrid`：数据模型抽出，纯 immutable，方便测试
- `WaveformCanvas`：网格线渲染逻辑与 pulse 完全解耦
