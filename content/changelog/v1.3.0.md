## 🎼 组合模板编辑器 · 里程碑功能

不再受限于内置节奏型，你可以：
- 拖拽 8 种基础节奏型（四分、八分、十六分、三连音、附点、切分等）自由组合
- 支持 4 / 8 / 16 拍长度
- 实时预览节拍器伴奏
- 保存到本地模板库，可编辑 / 删除 / 复制

## 💾 存档

- SQLDelight 双端本地库（Android / iOS）
- 可导出模板为 JSON 分享给鼓友（v1.4.x 起会支持直接分享链接）
