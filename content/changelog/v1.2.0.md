## 🍎 iOS 端首次公测

历时 3 个月的 KMM 跨平台改造终于收官：
- **iOS 端上线 TestFlight**：与 Android 端使用同一套 Kotlin 业务代码
- **共享层**：算法（Onset / Beat）、领域模型、数据层、ViewModel 全部跨平台
- **各端原生**：UI 层 Android 用 Compose / iOS 用 SwiftUI 分别实现

## 🌐 架构

- Kotlin Multiplatform Mobile（KMM）
- Clean Architecture 五层分离
- expect / actual 平台抽象（AudioRecorder / AudioEncoder / AudioDecoder 等）
