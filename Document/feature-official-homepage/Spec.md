# 官网正式实现 Spec

日期：2026-10-17。依据：本会话已通过的视觉稿 04，以及用户“先按这个效果，现在开始动工开发”。本次覆盖旧官网 PRD 中与当前决定冲突的配色、导航与范围，保留历史内容。

Goal：把已经审定的红黑官网视觉稿接入现有 Hugo 仓库，提供真实 App 截图展示、独立功能页面、版本记录与可用安装路径。

Scenario：访客打开首页了解 App，在四张真实截图之间切换，通过顶部导航进入独立页面，下载 Android APK 或打开 iOS TestFlight。

Boundary：页面内容来自 Hugo Markdown、功能数据和站点配置；截图为用户提供的原图；Android 包来自本地 v2.1.0 release 文件；iOS 邀请链接已由用户提供并配置。只修改官网仓库，不修改 App、个人博客或原始截图。发布到用户确认的官网专用仓库，不覆盖博客站点。

## Acceptance

1. AC1：红黑主题、放大的品牌与下载按钮；无右侧菜单、无“每一下都更准”及副标题；四项介绍放在图外上方。
2. AC2：首页、功能、版本记录、下载使用独立 URL；四个功能分类分别有子页面，导航高亮正确；支持直接打开与刷新。
3. AC3：四张真实截图完整等比展示，容器切换不跳动；每 3 秒循环，支持手动、键盘及暂停，后台暂停，遵守减少动态效果设置。
4. AC4：去除 mock 标记与编造的发布日期；版本来自已存在的 release Markdown，新增 v2.1.0 记录依据本地 tag（2026-07-30，d891798）。
5. AC5：Android CTA 下载包含已签名 APK 的 ZIP 压缩包，展示版本与 ZIP 大小，安装说明包含解压步骤，不显示 SHA-256 及其值；构建校验 ZIP 与内含 APK 的完整性并拒绝直接发布 APK；iOS 邀请未配置时提供“申请内测”的联系入口，配置后显示 TestFlight 邀请，安装说明提供无法安装时的微信联系方式 `Wenshy_2048`；不构造未验证的 GitHub Release URL。
6. AC6：Hugo 生产构建、JS 语法和交互测试、内部链接与资源检查通过；验证根路径与 GitHub Pages 子路径，以及 390px / 320px 窄屏。
7. AC7：保留现有手册、隐私政策与历史记录可访问；提供维护说明、配置入口和构建检查。

Out of scope：App 功能变更、自动同步 App 发布、社交表单新接入、域名购买、远端仓库创建和生产部署。
